# MTS-Library-Dashboard
A repository that stores a link to a Yandex DataLens Dashboard based on open data of MTS Libary

Dashboard could be accessed via this link: https://datalens.yandex/68vz2xiipc5ep?_share_link=public
The data from [MTS Library dataset on Kaggle](https://www.kaggle.com/datasets/sharthz23/mts-library/data?select=interactions.csv) was used
